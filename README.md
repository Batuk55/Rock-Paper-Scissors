## 📌 About The Project

Rock Paper Scissors is a browser-based game developed using fundamental web technologies.

The player competes against the computer by selecting one of three choices: Rock, Paper, or Scissors. The computer randomly generates its move, and JavaScript determines the winner based on the game's rules.

The application dynamically updates the scoreboard and displays the result of each round.

This project helped me strengthen my understanding of JavaScript fundamentals, DOM manipulation, event handling, and interactive web development.

---

## ✨ Features

- 🎮 **Interactive Gameplay:** Play Rock Paper Scissors against the computer.
- 🤖 **Computer Opponent:** Computer generates a random choice for every round.
- 📊 **Live Scoreboard:** Tracks both player and computer scores.
- 🏆 **Winner Detection:** Automatically determines the winner of each round.
- 🎨 **Dynamic UI:** Displays different messages for winning, losing, and drawing.
- ⚡ **Instant Results:** Results are displayed immediately after selecting a move.
- 🖥️ **Browser-Based:** No installation or account required to play.

## 🎯 Game Rules

The game follows three simple rules:

| Your Choice | Beats       |
| ----------- | ----------- |
| 🪨 Rock     | ✂️ Scissors |
| 📄 Paper    | 🪨 Rock     |
| ✂️ Scissors | 📄 Paper    |

- If both players choose the same option, the round is a draw.
- Otherwise, the winner is determined according to the rules above.

---

## ⚙️ How It Works

1. The player selects Rock, Paper, or Scissors.
2. JavaScript generates a random choice for the computer.
3. Both choices are compared using conditional statements.
4. The game determines whether the player wins, loses, or draws.
5. The scoreboard updates dynamically.
6. The player can continue playing additional rounds.
